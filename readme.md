# 🏥 Clínica Vida Saudável

Site institucional de uma clínica médica, desenvolvido como **Desafio de Projeto** do módulo de HTML da trilha Front-End da [DIO](https://www.dio.me/).

O objetivo é praticar, em um site "quase completo", tudo o que foi visto no módulo: formulários, estruturação e formatação de texto, mídias e tabelas.

## 🔗 Demonstração

https://DestroyerIG.github.io/clinica-vida-saudavel/

## 📄 Páginas

| Página | Arquivo | Conteúdo |
|---|---|---|
| Página Principal | `index.html` | Imagem no header e breve descrição da clínica |
| Sobre a clínica | `sobre.html` | Texto institucional, missão, valores, vídeo e áudio |
| Horário de Atendimento | `horarios.html` | Texto sobre os serviços e tabela de horários por serviço |
| Contato | `contato.html` | Telefones, endereço, mapa do Google Maps e formulário de contato |

Todas as páginas seguem o mesmo padrão: **menu de navegação**, **header com imagem**, **content** e **footer com informações de contato**.

## 🧩 Conteúdos do módulo utilizados

- **Estrutura e texto:** `h1` a `h3`, `p`, `b`, `i`, `u`, `strong`, `em`, `blockquote`, listas `ul` e `ol`, links
- **Imagens:** `img` com `alt` e `width`
- **Mídias:** `video`, `audio` com `controls`, `source` e `track` (legendas com `default`)
- **Tabelas:** `table`, `caption`, `thead`, `tbody`, `tfoot`, `tr`, `th`, `td`, `colspan`, `border`, `cellpadding`, `cellspacing`, `align`
- **Formulários:** `form` (`action` e `method`), `fieldset`, `legend`, `label`, `input` (`text` e `email`), `textarea`, botões `submit` e `reset`, validação com `onsubmit`
- **Conteúdo externo:** `iframe` com o Google Maps

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/DestroyerIG/clinica-vida-saudavel.git
   ```
2. Entre na pasta:
   ```bash
   cd clinica-vida-saudavel
   ```
3. Abra o arquivo `index.html` no navegador (duplo clique ou botão direito > Abrir com).

Não é necessário instalar nada.

## 📋 Requisitos do desafio

- [x] Menu de navegação: Página Principal, Sobre a clínica, Horário de Atendimento e Contato
- [x] Imagem diferente no header de cada página
- [x] Menu e footer iguais em todas as páginas
- [x] Tabela de horários com os serviços (Clínica geral, Psicologia, Pediatria e Oftalmologia)
- [x] Telefones (celular e WhatsApp) e endereço completo
- [x] Iframe do Google Maps com o endereço da clínica
- [x] Formulário com nome, e-mail, assunto, mensagem e botões de enviar e limpar
